# AIUE Project Workspace

AIUE is a mixed project workspace containing the maintained Mental-LLM application, research material, project documentation, validation evidence, and academic deliverables.

## Current Source Of Truth

| Responsibility | Current owner | Rule |
| --- | --- | --- |
| Maintained application | `Mental-LLM_JxFdj/` | Edit `src/`, `server/`, and maintained project files there. |
| Application technical docs | `Mental-LLM_JxFdj/docs/` | Architecture, operations, live integration, and application testing guidance. |
| Project-level knowledge | `md/` | Research sources, design notes, development plans, progress, validation, and reusable AIUE explanations. |
| Curated deliverables | `outputs/` | Existing reports, presentations, meeting records, and other handoff material. Its mixed historical structure is preserved during the first migration stage. |
| Persistent evidence | `artifacts/` | Screenshots, presentation review material, QA evidence, and other records that are useful but are not source code or formal deliverables. |
| Workspace automation | `scripts/` | Report generation, document conversion, and workspace-level maintenance scripts. |
| Historical material | `archive/` and `initial/` | Preserve old prototypes and snapshots; do not use them as current implementation sources. |
| Disposable files | `tmp/` and application build/cache directories | Regenerate or remove after confirming no evidence depends on them. |

## Application Boundary

`Mental-LLM_JxFdj/` is the maintained application. Its source of truth is `src/`; `public/runtime/` is generated by `npm run runtime:build`; `dist/` is build output; `node_modules/` is a dependency directory. Do not manually edit generated runtime files.

The runtime path is:

```text
browser -> local proxy -> NK-GeniOS Agent -> report-to-feishu workflow
```

The project is a non-diagnostic research prototype. Current safety, data-boundary, and live-integration claims must be grounded in the handoff and validation records under `md/00-project/`, `md/04-development/`, and the application `docs/` directory.

## Current Migration Status

This workspace is in the first structure-governance stage. The active application, `md/`, `outputs/`, and historical `initial/` paths remain unchanged to preserve existing references. Root-level UI screenshots and presentation-review material have been moved into `artifacts/` with their original names and dates.

The next migration stage should separate living design and research documents from final deliverables, resolve the application `tests/` versus `testing/` overlap, and update stale historical paths only after a full reference sweep.
