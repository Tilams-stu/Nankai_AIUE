# 2026-07-31 对话优先架构重构

## 已完成

- 对话回复不再依据缺失字段、字段优先级或既定问卷顺序追问。
- 新增本地轮次解释与交互状态：区分用户本人、第三方、虚构、转述和假设内容；识别“先别分析”“不要问了”等会话边界。
- 后台测评保持开启，但第三方、虚构、转述和假设内容不会写入学生测评状态或触发风险升级。
- 代理请求携带有序近期对话与强制响应计划；自然追问最多一题，“不要问了”时禁止提问。
- 在出现有意义的本人陈述或安全状态变化时，自动生成或更新报告 payload，并通过 Agent 内部工作流路径随该轮 Agent 请求传递。
- 保留结束会话按钮；它会触发一次最终报告更新，而不会向学生展示报告生成过程。
- 同一状态指纹不重复派发自动更新；结束会话可以强制派发最终更新。
- 只有本地测评状态实际变化或安全状态变化才触发自动更新，问候、闲聊和自然收束语不会污染主诉或新建空报告。
- 睡眠延迟、学习效率下降和社交回避会分别写入睡眠与功能影响字段；仅提及家人不会被误写为已获得支持。
- `free_chat` 会持续到学生明确恢复分析、结束，或安全优先处理；普通后续输入不会使其失效。
- 新增直接路由：风险语义澄清、专业帮助决策、同伴支持、虚构创作和医疗不适均先回答当前问题，避免回落到字段追问。
- 未完成安全询问的报告明确说明“不能据此推断不存在风险”；信息有限时不强制生成泛化转介建议。
- 移除了学生端“暂停会话”控件，保留结束会话按钮，符合后台测评不由学生控制的既定边界。

## 当前边界

- 本地端只能确认 payload 已登记并交给 Agent；真实飞书工作流是否完成仍需在 Agent 或后台日志中确认。
- 报告访问控制、人工高风险复核和学校心理中心联系方式尚无外部条件，未在本次重构中伪造实现。
