# 用户测试反馈表与测试总结报告

## 文档用途

本文件包含两部分：

1. 测试者完成对话后的反馈表；
2. 项目负责人根据反馈、日志和报告记录整理的测试总结报告模板。

两者都用于评价原型的交互体验和功能稳定性，不用于给测试者做心理诊断，也不替代专业心理测评。

## 一、测试者反馈表

### 1. 测试说明

请像平时聊天一样与智能体交流约 5～10 分钟，可以描述一个近期困扰，也可以自然地转换话题。不需要主动点击“生成报告”；如果想结束，可以使用页面中的结束功能。

测试过程中可能会产生对话记录和后台分析记录。记录仅用于本课程项目的功能验证和改进，不在学生端展示完整心理报告。测试者可以随时停止测试。

### 4. 开放题

1. 哪一句回复让你觉得最自然？为什么？
2. 哪一句回复让你觉得不自然、机械或答非所问？
3. 是否出现了重复追问、忘记前文或突然换话题？请描述具体情况。
4. 是否遇到打不开页面、发送失败、长时间等待或其他错误？
5. 你希望智能体增加、减少或改变什么行为？
6. 还有哪些建议？

### 5. 测试者结束确认

- [ ] 我已完成一次对话体验。
- [ ] 我知道本次测试用于课程项目功能验证，不构成心理诊断。
- [ ] 我同意项目负责人使用本次反馈改进原型。

### 2. 测试目标

本次测试主要验证：

- 对话是否自然，是否像倾诉和交流而不是信息采集；
- 多轮对话和话题切换时是否保持上下文；
- 信息充分后是否能在后台自动创建或更新报告；
- 用户不主动生成报告时，后台是否仍能留下记录；
- 结束操作、异常请求和网络异常是否有可接受的处理结果。

### 7. 结论与边界

结论应说明系统在本轮测试中已经验证的能力、仍然存在的问题和下一步优先级。

如果没有真实用户，应使用以下表述：

> 本轮未获得足够的真实用户样本，因此不对用户满意度、心理评估准确性或临床有效性作结论。当前结果仅来自开发者场景验证，另附一份可由指导教师或后续测试者执行的远程测试方案。
