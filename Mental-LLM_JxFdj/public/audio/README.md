# 白噪音资源目录

将已取得使用许可的音频放入本目录。当前页面严格使用以下 5 个文件：

- `rain.mp3`
- `forest.wav`
- `bonfire.mp3`
- `wind.mp3`
- `night.mp3`

每次只能播放一个音频；开始播放新音频时，正在播放的其他音频会自动暂停。页面仅在浏览器可实际加载和播放资源后显示“正在播放（单独播放）”，加载失败时显示“音频资源不可用”。

请仅使用具备公开播放/分发许可的资源；白噪音空间用于短暂放松，不应描述为治疗或危机处置。
