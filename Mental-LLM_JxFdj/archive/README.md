# Archive

This directory stores material that is not part of the running application.

- `history/docs/`: superseded refactor, asset-migration, and presentation notes.
- `history/progress/`: historical implementation progress note.
- `history/testing/`: historical teammate handoff check.
- `history/removed-files/`: non-runtime source-package copies retained during cleanup.
- `rollback-baseline/`: pre-refactor file manifest and static-asset rollback copies.
- `test-evidence/workflow-audit-2026-07-31/`: local workflow audit records produced during testing. These files can contain student identifiers and dialogue text. They are intentionally excluded from version control and must not be used as application source.

The active project paths are `src/`, `public/`, `server/`, `scripts/`, `tests/`, and `docs/`.
