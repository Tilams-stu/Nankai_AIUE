# 开发资料索引

本目录按开发生命周期收纳计划、执行记录与验证证据。

- `roadmap/`：当前和近期的实施计划。以最新日期、未标注“历史参考”或“已废止”的文件为准。
- `progress/YYYY-MM-DD/`：按日期收纳的实施留档。2026-07-31 的工作索引可作为近期进展的总览。
- `validation/YYYY-MM-DD/`：按日期收纳的测试结果、问题台账和复核证据。

已明确被主计划取代的两份 2026-07-24 路线图位于 `../90-archive/superseded-roadmaps/`。保留它们是为了追溯，不应作为新的执行依据。

新增开发文档时，先创建计划，再保存验证证据，最后写一份可链接到二者的进度留档。具体命名和格式见 [文档规范](../文档规范.md)。
