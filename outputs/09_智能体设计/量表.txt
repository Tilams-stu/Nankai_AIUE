字段未采集时必须为 `unknown/未询问`，不能默认记为 `no/否`。




| R0 未见明确即时风险 | 当前材料未发现明确即时危险 | 明确否认当前风险，且无其他重大线索 | 继续评估，保留不确定性 |
| R1 需要关注 | 有消极想法、明显功能下降、既往风险或其他需尽快专业评估的因素，但当前未见正在发生的危险 | 被动死亡愿望、既往自伤、支持不足等 | 完成必要澄清，建议尽快专业支持，自动报告上传 |
| R2 高度关注 | 多项风险因素叠加、主动意念、方法可及、近期计划、无法稳定确认安全，或严重精神状态线索 | 有计划但时间不明、独处且无支持、幻听命令等 | 立即提示联系现实支持、学校心理健康中心或紧急服务，并记录需关注状态 |
| R3 紧急 | 伤害正在发生、已经受伤/过量服药、计划即将实施或用户明确无法保证当前安全 | 当前实施、近期明确时间、严重身体危险 | 建议立即联系当地紧急服务/医疗机构、现场可信任人员或学校心理健康中心资源 |
| RX 信息不足 | 关键安全问题拒答、表达冲突、技术中断或模型无法可靠判断 | 风险表达后失联、主体/时间不清 | 保守处理，推送安全信息并自动报告上传 |


| 规则编号 | 触发条件 | 默认动作 |
| CR-001 | 正在伤害/已受伤/疑似过量服药 | R3，紧急医疗路径 |
| CR-002 | 近期明确计划或无法保证安全 | R3，提示紧急服务/校内资源并记录需关注状态 |
| CR-003 | 主动意念 + 计划/工具可及 | 至少 R2，立即现实支持 |
| CR-004 | 被动死亡愿望 | C2 澄清，至少自动报告上传 |
| CR-005 | 伤害他人迫近风险 | R2/R3，按正式制度升级 |
| CR-006 | 命令性幻听或现实判断显著受损 | R2/R3，医疗评估路径 |
| CR-007 | 明显躁狂/冲动危险组合线索 | R2，精神科评估路径 |
| CR-008 | 量表风险条目阳性 | 中断量表，进入 C2 |

| CR-012 | 规则与模型冲突 | 采用较保守路由并自动报告上传 |
